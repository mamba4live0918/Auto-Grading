# 全程30秒片段初评与人耳抽样

本地地址：http://127.0.0.1:8874/

若服务未运行，在项目根目录执行：

```powershell
powershell -File apps/segment_review_20260930/start.ps1
```

启动器只启动本机研究项目的Python服务，并打开浏览器。服务仅监听127.0.0.1，不上传录音。

## 这轮初评

82份录音覆盖为730个窗口。当前按固定50分二分类：参考分≥50为好，<50为不好，共493好、212不好；另25段因不足10秒或发声不足5秒无有效分数。这25段是可评分条件不足，不是机器“不确定”中间档。指数仍为未校准的机器参考值。

每段用13项声学／中断候选特征计算，参考原65个已标片段。被评分录音的原人工标签不会进入给该录音评分的模型。现有原标签不复制给新窗口。

## 抽样流程

1. 默认打开60个固定抽样片段，来自60份不同录音。先听音频，选择“好／不好”，可写备注；没有判断的片段保持未评价。
2. 等“已写入本机服务器文件”确认后，可以查看机器初评作比较。
3. 查看初评后再改判断，最初的判断和是否看过机器提示会分别保留。
4. 可以按录音浏览全730段，查看各段状态和整段平均参考指数、较差时间占比、波动及连续较差时长。
5. “导出服务器已保存答案”下载JSON。答案本身已保存到 data/private/segment_pregrade_20260930/human_answers.json，刷新页面可恢复。

原声和降噪试听时间轴相同。答案记录试听音源，切源保留播放位置；播放自动在当前窗口结束处停止。

固定60段原本按高（≥65）／中（>35且<65）／低（≤35）初评分数区间分别抽取21／20／19段；这描述原抽样来源，不是当前机器的三个判断类别。按当前50分界线，这60段为34好、26不好。60段人耳核查已完成，33好、27不好；机器与人耳37/60一致（61.7%），有23段分歧。全部60段均进入当前二分类比较。它是覆盖不同分数区间的分层样本，不能将61.7%外推为全部730段的总体正确率。原65参考窗口的留出AUROC约0.70也不等于新730段70%正确。[当前汇总统计](../../output/report_correlations_20260930/results.json)。

机器与人耳结果分开保存，程序不把机器初评自动当作训练真值。旧核查工具、原50处人耳标记、旧实验均保留。
